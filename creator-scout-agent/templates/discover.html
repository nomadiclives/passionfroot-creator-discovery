What this page is for

This is where a shortlist starts: finding people worth looking at. The app reads your brief and writes the searches for you, so you are not guessing what to type into TikTok. You click the ones that look useful, and paste back the handles you liked.

  1. Run some searches. Every tile below opens a real search on TikTok, YouTube, Instagram, LinkedIn or Reddit in a new tab. Start with a handful, not all {{ plan.total_queries }}.
  2. Paste back who you found. Profile links or handles, one per line. They join a pool you can screen, judge and score.

One thing to expect: the people you paste arrive with no numbers attached, marked NEEDS_REFRESH. A name you found in a search is a lead, not a measurement — the app will not invent a follower count to make the row look finished. You add the real numbers later.

1Run some searches

Each group below is a pass — a different angle of attack for finding the same kind of person. One sweeps hashtags and content, another looks at who your competitors have already paid, another reads communities. They surface different people, so it is worth running more than one. Each is closed to keep this page readable — open one to see its searches.

2Paste back who you found

One per line. A profile link is easiest — the platform is read out of the address. A bare handle (just @name, with no link) needs you to say which platform it is on, below, or it is skipped rather than guessed at. Run this as many times as you like; each paste adds to the same pool.

"Where you found them" is a note to your future self, kept on every row: which search turned this person up. The same creator arriving from two different passes is a good sign, and the app keeps that rather than collapsing it away.

Can the app search for me?

Partly, and it is optional. Running the searches yourself is the normal path here and nothing below is broken if it says otherwise.
